Robot Grasp Annotation

40 short sequences filmed by a camera mounted on a robot arm's wrist, 6 images each. For every image, say what the gripper is doing with respect to the articulated part being manipulated: a drawer, a door, a cabinet, a microwave. There are no trick questions and no expected answer: report what you see.

Your answers are saved automatically under this name. Come back later with the same name to pick up where you left off. If someone else might use the same first name, add an initial.

Holding

The articulated part (handle, knob, lever, edge of a panel) is gripped between the gripper's fingers.

Pushing

The gripper touches the articulated part without holding it, for example a closed gripper pressed against a drawer front.

None

No contact with the articulated part, including when the gripper holds some other object (a cup, a pen…).

Unsure

You cannot tell from this image.

  • Judge each image on its own.
  • Fingers open around the handle but not yet closed: None if there is no contact, Unsure if you cannot tell.
  • If you cannot tell Pushing from None, pick None or Unsure: Holding is the answer that matters most.
