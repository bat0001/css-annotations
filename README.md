# Robot Grasp Annotation

Static annotation page for a research study on robot manipulation evaluation (CRS, stage T1c).
Images: the DROID dataset (Khazatsky et al., 2024), CC BY 4.0.
Answers are saved under the annotator's first name to a private spreadsheet of the research team.

## drawer/ — Robot Drawer Annotation (CRS, stage V2-SOAR)

160 short clips of a WidowX arm on a drawer, three questions per clip.
Clips: the SOAR dataset (Zhou et al., 2024; github.com/rail-berkeley/soar), re-encoded to H.264 for web
browsers (frames unchanged) and named by anonymous id only.
